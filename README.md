# n95 Mask Tester

Developed electronics and mechanical control system for a device to measure the efficiency of a face mask. 

### Outcome
Prototype achieved accuracy +/- 2% with genuine masks. Surprisingly, most of the mask samples tested were not up to spec, including well-known brands.
